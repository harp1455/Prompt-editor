# 크랙 프롬프트 스튜디오

크랙 캐릭터 채팅 프롬프트를 파트별로 나눠 쓰고, 로어북·시작상황·버전·아이디어까지 한곳에서 관리하는 도구입니다. 윈도우와 안드로이드에서 함께 씁니다.

## 설치

이 저장소의 **Releases** 페이지에서 가장 위(최신) 항목을 엽니다.

- 윈도우: `CrackPromptStudio-Setup-버전.exe` 를 받아 실행합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
- 안드로이드: `.apk` 파일을 받아 엽니다. "출처를 알 수 없는 앱" 허용을 물으면 허용합니다.

## 업데이트

- 윈도우: 앱이 켜질 때 새 버전을 확인해 뒤에서 내려받고, 앱을 끄면 설치합니다.
- 안드로이드: 새 버전이 있으면 화면 위에 알림이 뜹니다. "새 APK 받기"를 눌러 받은 파일을 열면 덮어 설치됩니다.
- 설정 → "업데이트 확인"으로 직접 확인할 수도 있습니다.

## 기기 사이에서 작업 옮기기

상단 **파일 → 전체 백업 내보내기**로 만든 `.cps.json` 파일을 다른 기기로 보낸 뒤, 그 기기에서 **파일 → 파일에서 가져오기**를 누릅니다. API 키는 파일에 들어가지 않으므로 기기마다 한 번씩 넣어야 합니다.

## AI 기능

설정에서 Gemini API 키를 넣으면 검수, 요소 추천, 설계 상담, 압축을 쓸 수 있습니다. 요청마다 토큰 수와 예상 금액이 표시됩니다.
